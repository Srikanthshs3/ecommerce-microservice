Event-driven microservices architecture built with Spring Boot 3.4.x, Spring Cloud, and Apache Kafka. 
This project demonstrates a robust backend system featuring service discovery, centralized configuration,
API routing, asynchronous communication using Confluent Avro schemas, and comprehensive observability.

Architecture & Tech Stack : Core Technologies

Language: Java 21

Framework: Spring Boot 3.4.x, Spring Cloud

Event Streaming: Apache Kafka, Confluent Schema Registry (Avro)

Databases & Cache: MySQL 8.0, Redis 7.0

Observability (LGTM): Loki, Grafana, Tempo, Prometheus, Micrometer Tracing

Containerization: Docker & Docker Compose
